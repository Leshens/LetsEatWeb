# Let's Eat — Web Application

Web application developed as part of the Let's Eat restaurant application.

## Features

- Restaurant browsing
- User interface for the restaurant reservation platform
- Communication with the Let's Eat REST API
- Responsive web interface

## Technologies

- JavaScript
- React
- Tailwind CSS
- REST API
- HTML
- CSS

## Project

The application was developed as the web component of the Let's Eat restaurant platform.

It communicates with the backend REST API and provides users with a web interface for interacting with the application.

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server
```
npm start
```

The application will be available at:
```
http://localhost:3000
```
The page will automatically reload when changes are made.

## Available Scripts
```
npm start
```
Runs the application in development mode.
```
npm test
```
Runs the test runner in interactive watch mode.
```
npm run build
```
Creates an optimized production build in the build folder.

## Project Structure

The application is built with React and uses a component-based architecture.

The frontend communicates with the Let's Eat backend through the REST API.
